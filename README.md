# 🎨 自由畫板

給小朋友的免費線上畫板，功能對標市面上付費畫板 App，純前端、無廣告、免安裝。

**線上遊玩：** https://sancola1219-collab.github.io/drawing-board/

## 功能

- **10 種工具**：鉛筆、麥克筆、蠟筆、噴槍、彩虹筆、亮粉筆、螢光筆、油漆桶、印章、橡皮擦
- **🧸 196 個卡通印章**：動物、表情、食物、交通、自然、好玩 六大分類，點選後在畫布上蓋章
- **🖍️ 著色本**：10 張內建線稿（貓咪、蝴蝶、小魚、小房子、小汽車、花朵、小恐龍、火箭、冰淇淋、彩虹天空），搭配油漆桶一點就上色
- **🪣 油漆桶填色**：掃描線 flood fill，含反鋸齒容差，不會漏色到線外
- **🦋 對稱畫模式**：左右鏡像同步作畫
- **26 色調色盤 + 自訂顏色 + 粗細調整 + 7 種畫紙底色**
- **↩️ 復原 / 重做**（30 步）、一鍵清除
- **🖼️ 作品集**：收藏到瀏覽器（localStorage），隨時載回續畫
- **💾 存檔**：一鍵下載 PNG
- **📱 觸控支援**：手機平板都能畫

## 技術

單一 `index.html`，原生 Canvas 2D，無任何相依套件。

## 本機執行

直接用瀏覽器開啟 `index.html` 即可。
