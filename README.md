# 自由畫板 Atelier

高質感線上畫板 — 深色工作室風格介面，功能對標付費畫板 App。純前端、無廣告、免安裝。

**線上使用：** https://sancola1219-collab.github.io/drawing-board/

> 開發者／AI 助手接手請先讀 [docs/HANDOFF.md](docs/HANDOFF.md)（架構、不變式、測試與發佈流程）；`CLAUDE.md` 與 `AGENTS.md` 為精簡入口。

## 功能

- **11 種工具**：鉛筆、麥克筆、蠟筆、噴槍、彩虹筆、亮粉筆、螢光筆、油漆桶、印章、橡皮擦、移動
- **放大鏡**：×1.6 / ×2.4 兩段放大，搭配「移動」工具平移畫布，小區域也好點好塗
- **196 個圖章**：動物、表情、食物、交通、自然、好玩 六大分類，點選後在畫布上蓋章
- **著色本（469 張）**：10 張手繪經典場景 + 459 張卡通線稿（表情臉譜、人物角色與職業、動物王國、美味食物、交通工具、花草自然、玩具運動 七大分類），以油漆桶上色
- **照片變線稿**：選一張照片，即時調整線條細節與粗細，一鍵轉為黑白著色圖（純本機處理，照片不上傳）
- **油漆桶填色**：掃描線 flood fill，含反鋸齒容差，不漏色到線外；點到輪廓線自動吸附到鄰近區域
- **對稱模式**：左右鏡像同步作畫
- **26 色調色盤 + 自訂顏色 + 粗細調整 + 7 種畫紙底色**
- **復原 / 重做**（15 步、離屏快照零延遲）、一鍵清除
- **作品集**：收藏至瀏覽器（localStorage），隨時載回續畫
- **存檔**：一鍵下載 PNG
- **觸控支援**：手機平板皆可用
- **介面**：深色工作室主題、SVG 線條圖示、serif 標題、金銅色點綴

## 技術

單一 `index.html`，原生 Canvas 2D，無任何相依套件。

- **線稿轉換引擎**：卡通圖用色塊邊界偵測（顏色距離門檻）、照片用灰階→盒狀模糊→Sobel 邊緣偵測，再膨脹成粗線、二值化輸出，確保油漆桶填色不漏色
- **縮圖背景生成**：emoji 字型光柵化成本高（~20ms/張），用 MessageChannel 微任務泵分批生成（每輪 ≤24ms），隱藏分頁也不受計時器節流影響

## 本機執行

直接用瀏覽器開啟 `index.html` 即可。
